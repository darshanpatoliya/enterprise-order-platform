# Enterprise Order & Inventory Platform

An enterprise-style order and inventory management system built with
C# and ASP.NET Core.

## Goal

This project is being built to practice and demonstrate:

- Object-Oriented Programming
- SOLID principles
- Clean Architecture
- REST API development
- SQL and Entity Framework Core
- Authentication and Authorization
- Testing
- System Design
- Git/GitHub workflows
- Docker
- CI/CD
- Cloud deployment
